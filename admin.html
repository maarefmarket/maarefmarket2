📞 أرقام الواتساب

الرقم الأول هو الذي تُفتح عليه رسالة واتساب عند الزبون. الأرقام الإضافية تُرسل إليها نسخة عبر بوت تلغرام (إن ضُبط TELEGRAM_BOT_TOKEN). الصيغة الدولية بدون + مثل 9639xxxxxxxx.

💬 قالب رسالة الطلب

الرموز: {items} المنتجات · {totals} الإجمالي · {notes} ملاحظة الزبون · {store} اسم المتجر

🔐 كلمة مرور لوحة التحكم

تُدار من Netlify عبر متغيّر البيئة ADMIN_PASSWORD (8 أحرف على الأقل). تغييرها يُنهي كل الجلسات المفتوحة تلقائياً.

  1. Site configuration → Environment variables
  2. عدّل قيمة ADMIN_PASSWORD
  3. Deploys → Trigger deploy → Deploy site
