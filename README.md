# CampusKart — متجر الجامعة 🎓🛒 (v3 — نسخة مقوّاة)

متجر جامعي بواجهة عربية RTL مع **لوحة تحكم لحظية** — أي تعديل يُنشر فوراً لجميع الزوار.
الهوية البصرية مستوحاة من شعار **جامعة المعارف للعلوم التطبيقية (MAS)**: أزرق ملكي `#2B5FB3` + برتقالي `#F39C1F`.

## ✨ المميزات
- 🎨 هوية جامعة المعارف (أزرق/برتقالي) + وضع ليلي
- 🛍️ أقسام ومنتجات وأنواع (Variants) وعروض (سعر قديم مشطوب)
- 🧩 **مجموعات المنتجات**: عدة منتجات بنفس «اسم المجموعة» (مثل كنزا كولا 330 / 1 لتر / دايت) تظهر معاً في البحث، وفي صفحة أي نوع تظهر باقي الأنواع تحت الصورة للتنقل بينها. في اللوحة: زر «🧩+» بجانب أي منتج يفتح نموذجاً مسبق التعبئة لإضافة نوع شقيق، وزر «حفظ وإضافة نوع آخر» داخل النموذج
- 💵 3 عملات: USD / TRY / SYP مع أسعار صرف مركزية
- 🛒 سلة + طلب عبر واتساب برسالة قابلة للتخصيص + نسخة تلغرام للأرقام الإضافية
- 🧮 **الإجمالي مقسّم حسب عملة كل منتج**: كل منتج يُحاسب بعملة واحدة (الدولار إن كان ظاهراً، وإلا أول عملة ظاهرة له)، والرسالة والسلة تعرضان إجمالياً منفصلاً لكل عملة مع عدد المنتجات. الحساب بالقروش (×100) لتفادي أخطاء الفاصلة العشرية. إن كان القالب المخصّص بلا `{totals}` يُضاف تلقائياً. الأسعار المخزّنة كنصوص من النسخة القديمة (`"1.15"`, `"14,000"`, أرقام عربية) تُحلَّل بشكل صحيح، والنوع بلا سعر خاص يرث سعر المنتج، والمنتج بكل عملاته مخفية يُحاسب بأي عملة له سعر (لا يسقط من الإجمالي أبداً)
- ⚡ حفظ لحظي عبر Netlify Functions + Blobs مع سجل تاريخي (آخر 20 نسخة)
- 📸 رفع الصور من الجهاز (ضغط تلقائي) للمنتجات والإعلانات
- 🎨 **تبويب الألوان** في اللوحة: تعديل 16 لوناً لكل وضع (نهاري/ليلي) + 6 حزم جاهزة + معاينة مباشرة + استرجاع الأصل. تُحفظ في `settings.theme` وتُطبّق في الموقع كمتغيرات CSS
- 🚫 المنتج بحالة **غير متوفر** يُخفى كلياً من الموقع (القوائم، البحث، المجموعات، السلة) ويبقى في اللوحة فقط
- 🧷 كل تنقّل داخل المتجر (منتج/قسم/سلة/رئيسية) ينتقل لأعلى الصفحة **فوراً** بدون أنيميشن سحب (`behavior: instant` + `scrollRestoration = manual`)

## 🔐 التحسينات الأمنية في v3 (مقارنة بالنسخة القديمة)
| المشكلة القديمة | الحل |
|---|---|
| التوكن = كلمة المرور نفسها في localStorage | توكن جلسة **HMAC موقّع** صالح 12 ساعة، في sessionStorage، لا يحتوي كلمة المرور. تغيير كلمة المرور يُبطل كل الجلسات |
| لا حدّ للمحاولات | **Rate limit**: 8 محاولات/15 دقيقة لكل IP على الدخول، وحدود على الحفظ/الرفع/الإشعارات |
| مقارنة `!==` | `timingSafeEqual` |
| `CORS: *` | Same-Origin فقط |
| XSS عبر أسماء المنتجات في innerHTML | تهريب كامل `esc()` + منع روابط `javascript:` + تفويض أحداث بدل onclick |
| قبول أي بنية بيانات | `validate.js`: تنظيف عميق، حدود أطوال، حدّ 3MB، تحقق من الروابط |
| الوثوق بـ Content-Type للرفع | فحص **Magic bytes** للملف الحقيقي |
| `/api/notify` مفتوح | Same-Origin + 10 طلبات/10 دقائق |
| لا ترويسات أمان | `netlify.toml`: CSP, HSTS, X-Frame-Options, nosniff, noindex للوحة |
| كتابة فوق تعديل جهاز آخر | Optimistic locking عبر `X-Base-Version` (409 + خيار الكتابة فوقها) |

## 🐛 أخطاء برمجية أُصلحت
- تعديل منتج كان **يحذف الأنواع (variants)** → الآن تُدار من اللوحة وتُحفظ
- السلة كانت تُمسح عند تحديث الصفحة → تبقى خلال الجلسة وتُنظَّف من المنتجات المحذوفة
- أسعار الصرف كانت تترك كسوراً لليرة السورية → تقريب لعدد صحيح، وتشمل الأنواع والأسعار القديمة
- نص إرشادي خاطئ عن أرقام الواتساب → مُصحَّح (الأول للزبون، البقية عبر تلغرام)
- انهيار الجدول عند غياب `prices` → تطبيع البيانات
- الشعار `/assets/logo.svg` كان مفقوداً → أُضيف
- `data-default.json` لم يكن يُضمَّن مع الدوال → `included_files` في netlify.toml

## التسعير المركزي وآراء الزبائن

- الدولار هو مرجع التسعير. من تبويب أسعار الصرف أدخل قيمة الدولار بالتركي والسوري ثم احفظ؛ تُعاد حسابات المنتجات والعروض والأنواع من الدولار، دون تكرار التحويل من سعر محلي سبق تقريبه.
- التقريب إلى أقرب 0.01 USD، وأقرب 0.5 TRY، وأقرب 10 SYP؛ عند التعادل إلى الأعلى. يُحسب إجمالي السطر من سعر القطعة بعد التقريب.
- الأسعار القديمة التي لا تتضمن USD تستفيد من أسعار الصرف المتاحة لترحيلها إلى الدولار. إذا لم توجد قيمة أو سعر صرف صالح يجب إدخال سعر الدولار للمنتج.
- قبل الطلب يظهر رأي اختياري. التخطي لا يحفظ رأياً ولا يعطل الشراء. لا تُرسل الآراء إلى WhatsApp أو Telegram؛ يُرسل الطلب بالطريقة السابقة.
- يحفظ /api/feedback الرأي والمنتجات والكميات والأسعار من الكتالوج مع وقت الاستلام UTC، ويعرضه في تبويب آراء الزبائن بتوقيت دمشق. السجل منفصل في Netlify Blobs باسم campuskart-feedback؛ لا يُخزّن الاسم أو الهاتف أو ملاحظات الطلب أو IP في سجل الرأي. يُستخدم محدد معدل منفصل ببصمة يومية مشتقة من IP لمكافحة الإغراق. لا يُثبت السجل أن الزبون أرسل رسالته في واتساب.
- القراءة من السجل تتطلب جلسة إدارة صالحة. النسخ التجريبية لا تحفظ آراء حقيقية ولا ترسل رسائل فعلية. تغيير أسعار الصرف وتسجيل الآراء يحتاج اختباراً فعلياً على بيئة النشر.
- `npm test` يتضمن اختبارات التقريب والطلبات والخصوصية وسلوك النافذة، و`npm run build` ينشئ ملفات النشر العامة.


## المراسلات المجهولة — إضافة مستقلة قابلة للتراجع
- النسخة الجديدة مغلقة افتراضياً في الإنتاج. من لوحة التحكم > آراء الزبائن > المراسلات المجهولة، فعّل أو أوقف النظام بمفتاح مستقل يُحفظ مباشرة، ولا يحتاج حفظ الكتالوج.
- الإيقاف يعيد نافذة الاقتراحات القديمة ويوقف العمليات الجديدة والإشعارات الجديدة. تبقى المحادثات محفوظة في `campuskart-support-v1` ويمكن قراءتها إدارياً وإعادة تفعيلها لاحقاً. قد تصل إشعارات سبق إرسالها قبل الإيقاف.
- كل محادثة جديدة تحفظ الرأي الأصلي أيضاً في سجل `campuskart-feedback` بنفس معرّف المحاولة لمنع التكرار. الآراء القديمة غير قابلة للرد بأثر رجعي. لا تُمس ملفات أو مخزن المنتجات.
- رمز استرجاع المحادثة سر عشوائي 256 بت، تحفظ بصمته فقط على الخادم. لا تضع الرمز في رابط أو نص رسالة. فقد الرمز وبيانات المتصفح يعني فقد إمكانية الوصول. الاشتراك بالإشعارات اختياري لكل محادثة، ويحفظ آخر جهاز اشترك بها. لا يُعرض عنوان اشتراك الإشعار أو مفاتيحه للإدارة.
- مفاتيح VAPID تُنشأ مرة واحدة في المخزن الخاص، ولا تُضمّن في المستودع. عامل الخدمة يستقبل الإشعارات فقط، دون كاش أو اعتراض طلبات المتجر. لا يحوي الإشعار نص الرسالة. آيفون/آيباد يتطلبان إضافة الموقع للشاشة الرئيسية على الإصدارات الداعمة.
- المعاينة: افتح المتجر مع `?supportDemo=1` والإدارة مع `?demo=1` في نفس ملف المتصفح. الرسائل افتراضية في localStorage على أصل المعاينة فقط، ورد الإدارة محاكاة محلية. زر اختبار إشعار حقيقي مستقل يرسل إشعاراً تجريبياً لهذا الجهاز فقط عند موافقته، باستخدام مفاتيح ومحدد معدل في مخزن خاص بالنشر التجريبي. لا تكتب معلومات حقيقية في المعاينة. لا يعد اختبار النقل التجريبي اختباراً كاملاً لردود الإنتاج.
- نقطة الرجوع البرمجية قبل إضافة المراسلات: `2c9d67621877f0b2e305c7799e1575de724e670d`. استخدم مفتاح الإيقاف أولاً؛ لا تستورد نسخة قديمة من المنتجات للرجوع. إذا لزم التراجع برمجياً، اعكس التغييرات الخاصة بهذه الإضافة فقط مع إبقاء بيانات Blobs الحالية.
